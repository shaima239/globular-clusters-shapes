# Measuring the Shapes of Globular Clusters with Gaia

**Author:** Al Shaima Al Rawahi  

This repository contains the code and data used in the undergraduate thesis *"Measuring the Shapes of Globular Clusters with Gaia"*.

## Overview

Globular clusters (GCs) are dense stellar systems found in the Milky Way. This project uses Gaia EDR3 data (Vasiliev & Baumgardt 2021) to measure the ellipticity and position angle of 126 Galactic globular clusters. The analysis includes:

- Spatial distribution and colour‑magnitude diagrams
- Radial density profiles to identify Gaia's incompleteness at cluster centres
- Calculation of ellipticity and position angle using the covariance matrix of member stars
- Histograms of the measured parameters
- Comparison with literature (Chen & Chen 2010) and exploration of mass–ellipticity correlations
